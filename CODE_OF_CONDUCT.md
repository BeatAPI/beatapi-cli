# Contributor Covenant Code of Conduct

We are committed to a welcoming, harassment-free community for everyone.
Contributors must communicate respectfully, accept constructive feedback, and
focus discussion on improving BeatAPI users' experience.

Unacceptable behavior includes harassment, discrimination, threats, deliberate
exposure of private information, and publishing credentials or private user
media.

Project maintainers may remove or reject contributions and community
participation that violate these expectations. Report conduct concerns
privately through the repository owner's GitHub profile. Security issues belong
in GitHub private vulnerability reporting instead of public issues.

This policy is adapted from the Contributor Covenant, version 2.1.
